# DEVCARD – GitHub Profile Dashboard 🧑‍💻

A GitHub profile dashboard that fetches and displays developer information and repository statistics using the GitHub REST API.

### Features
- Search GitHub profiles using usernames.
- Display profile information and statistics.
- Explore public repositories.
- View repository stars and programming languages.
- Search, filter and sort repositories.
- Visualize programming language distribution.
- Loading states and error handling.

### Tech Stack
- HTML5
- CSS3
- JavaScript
- GitHub REST API

### Run Locally
1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
